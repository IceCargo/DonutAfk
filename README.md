# Donut AFK

A lightweight Rust-based terminal Minecraft AFK client.

Donut AFK allows you to stay AFK on Minecraft servers without running the actual Minecraft client. The entire client runs through the terminal, which reduces RAM usage and overall system resource consumption.

supports on Windows and Linux.

## Features

- Written in Rust
- Runs completely in the terminal
- No Minecraft client required
- Microsoft account login through the console
- Server IP can be changed
- Can be used to afk at Spawners
- Low resource usage
- Commands like /bal, /shards work

## How it works
Windows: Start the Executable trough the terminal opened in the same directory like this: ./DonutAfk.

After logging in, the script will automatically connect you with your linked Microsoft account and join the configured server for example DonutSMP to farm shards.

The server IP can be changed directly in the source code. After changing the IP, the project needs to be rebuilt to apply the changes.
